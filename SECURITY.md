# Security Policy

## Supported versions

The latest released version receives fixes. ShotEditor is a local-only app: it
does not upload your screenshots, use accounts, or send telemetry.

## Permissions it requests

- **Screen Recording** — required by macOS for `screencapture` to see window
  contents. Without it macOS only returns the desktop wallpaper.
- **Files (user-selected)** — to save where you choose.

## Reporting a vulnerability

Please report security issues privately by opening a
[GitHub security advisory](../../security/advisories/new) or emailing the
maintainer, rather than filing a public issue. You'll get an acknowledgement
within a few days.
